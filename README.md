## Make it yours

1. Select **Use this template → Create a new repository**. Choose `gdi-ucl` if you are a member, or your own account. Choose Public or Private and leave **Include all branches** off.
2. Open **COPY-THIS-README.md**, use the copy control or Raw view to copy the Markdown text, then open **README.md → Edit** (pencil).
3. Paste the blank format, replace the bracketed instructions, select **Preview**, and **Commit changes** to main.
4. Upload permitted project files and share the link. Keep the existing banner line above your new text if you want the purple GDI styling.

**You can also copy the blank format into an existing repository’s README.** Keep any useful existing instructions and attribution.

## Minimum needed

A title, a short explanation, a named contact and a useful file/publication link. Add other sections only when they help your readers.

For an example of this format filled with real source information, open [Innovate Now: Lessons](https://github.com/gdi-ucl/innovate-now-lessons).
