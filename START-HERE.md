# Create, upload and share — no coding needed

## 1. Create

[Use this template](https://github.com/gdi-ucl/project-template/generate). Choose the project owner, a short repository name and Public or Private. Creating inside gdi-ucl requires membership and repository-creation permission. Everyone can read this public template without joining.

## 2. Fill in

Copy COPY-THIS-README.md into README.md, replace the bracketed prompts, preview, and commit to main. A commit simply saves a named version. PROJECT metadata files and reviews are not mandatory.

## 3. Upload

Open the destination folder → **Add file → Upload files** → select files → enter a short description → **Commit changes**. Browser limits are currently 25 MiB per file and 100 files per upload. Keep your existing folder layout if it works.

Use GitHub for content allowed by the relevant UCL/project guidance. Link to approved storage for research datasets, participant material, slides and other assets. Inspect notebook outputs and never upload credentials.

## 4. Share

Copy the project URL. Public projects can be read without an invitation. For private projects, a repository Admin must give intended collaborators Read or Write access first. A URL alone does not grant access. Only publish work you have permission to disclose.

Project leads use repository Admin to control visibility and collaborators. Contributors use Write for uploads. Direct saves to main are the default here; branches and reviews are optional unless your project has rules.

## Existing GitHub repository

To retain its history, an authorised repository administrator can use Settings → General → Danger Zone → Transfer ownership to move it into gdi-ucl, subject to destination permissions. Verify visibility, access and integrations afterwards. Alternatively, copy the README format into the existing repository without moving it. Uploading files alone is a snapshot, not a history transfer.

## Publication page

Start with the publication title, verified author information, a short original summary and the source link. Link to the authoritative PDF/publisher instead of copying the full publication into GitHub. Add a DOI/year only when verified.
